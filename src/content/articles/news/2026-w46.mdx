## 要点

1. 新しいモデル：Claude Fable・Mythos 5.2 と Gemini 4 Hydrogen が出て、Gemini 4 Carbon が一般提供になった
2. 対応が必要なのは5件。Claude API・Claude Code・Cowork・Codex を、仕事の自動化に使っている人が中心
3. Claude には、Sheets・Whiteboards（ベータ）と、Google Meet の会議への参加（ベータ）が加わった
4. ChatGPT には、事業者向けの Businesses in ChatGPT と、買い物を任せる ChatGPT Wallet が出た
5. Midjourney・FLUX・Sora には、この週の公式の変更は見つからなかった

## 対応が必要な人

| 使い方                                                         | すること                                                                                                        |
| -------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| Claude API で Fable・Mythos 5.2 に切り替える                   | 古い computer tool（`computer_20251124`）を新しいものに移す。thinking を返す前に system や tools を書き換えない |
| Claude Code のサンドボックスで、確認なしに Bash を動かしていた | 確認なしに戻すなら、設定に `sandbox.autoAllowBashIfSandboxed: true` を書く                                      |
| Claude Code で、未登録のモデル ID を使っている                 | コンテキストが小さいモデルなら、`CLAUDE_CODE_DISABLE_1M_CONTEXT=1` を設定する                                   |
| Cowork のネットワーク制限つきタスクで git push をしていた      | push・Git LFS・SSH のリモートは使えない。手元で push する                                                       |
| CI などで `codex exec` を使っている                            | プロジェクトの設定と MCP を使うなら、`--trust` を付ける                                                         |

## 日付の見方

- 日付は、各社の発表に書かれた日付（多くは米国時間）。日本時間では翌日のことがある
- 各変更の詳しい条件は、表の行からたどれる公式のページで確かめる
