## 3行でいうと

1. AI が1回の返事を作るときに見渡せる量（作業机の広さ）
2. 指示・これまでの会話・渡した資料・今回の返事まで、全部がこの中に入る
3. いっぱいに近づくと、古い話が押し出されたり、読み落としが増えたりする

## たとえば

```text
はじめ：「この表の売上を、月ごとにまとめて」
  …（資料を何度も貼り、長いやりとりが続く）…
いま　：「最初の表の 3 月の数字は？」
AI　　→ 最初の表が押し出されていて、正しく答えられないことがある
```

- チャットの画面では、古いやりとりから押し出されることがある
- 量の数え方は、[トークンとは](/ai-basics/what-is-token/)で説明している

## 何が入るのか

```text
┌──────────── コンテキストウィンドウ ────────────┐
│ 指示（システムプロンプト）                       │
│ これまでの会話（人の発言と AI の返事）           │
│ 渡したファイル・画像・道具の結果                 │
│ 今回の質問                                       │
│ 今回の返事（考えた過程を含む）                   │
└──────────────────────────────────────────────┘
```

- 量はトークンで数える
- 会話が続くほど、前のやりとりが積み上がる
- 学習に使われた大量のデータとは別物で、その場の「作業の記憶」に当たる

## 大きさの目安

|        | 見るところ                                                                                            |
| ------ | ----------------------------------------------------------------------------------------------------- |
| Claude | [モデルの一覧](https://platform.claude.com/docs/en/models/overview)（モデルごとに大きさが書いてある） |
| Gemini | [トークンの説明](https://aistudio.google.com/docs/tokens)（モデルの世代ごとに書いてある）             |

大きさはモデルと時期で変わるので、ここには数字を書きません。広いほど一度に多く渡せますが、それだけ良い答えになるとは限りません。

## いっぱいになると何が起きるか

| 場面                           | 起きること                                         |
| ------------------------------ | -------------------------------------------------- |
| API で、入力だけで上限を超える | エラーになり、返事が来ない                         |
| API で、返事の途中で上限に届く | 返事が途中で止まる                                 |
| チャットの画面                 | 古いやりとりから押し出されることがある             |
| 長い作業をするツール           | 前の部分を要約して、続けられるようにするものがある |

<Callout>
  量が増えるほど、細かいところの読み落としが増えることがあります。広さより、何を入れるかを選ぶほうが効きます。
</Callout>

## 上手に付き合うには

1. 話題が変わったら、新しい会話を始める
2. 長い資料は、必要な部分だけを渡す
3. 長い作業は、途中の結果をファイルなどに書き出しておく
