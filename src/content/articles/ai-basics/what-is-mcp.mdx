- **ひとことで**：AI のアプリに、外のデータや道具をつなぐための共通の決まり
- **読んだあと**：設定画面や記事の「MCP サーバー」が、何をつなぐものか分かる
- **前提**：なし（3分で読める）

## なぜ共通の決まりが要るのか

|          | 決まりがないとき               | MCP があるとき                              |
| -------- | ------------------------------ | ------------------------------------------- |
| つなぐ側 | アプリごとに別々の作り方       | 1つの作り方で、対応したアプリ全部につながる |
| 使う側   | アプリを変えると設定をやり直す | 同じサーバーを別のアプリでも使える          |

公式の説明では、いろいろな機器を1つの形でつなぐ USB-C にたとえています。Claude、ChatGPT、VS Code、Cursor などが対応しています。

## 登場する3つの役割

```text
ホスト（AI のアプリ：Claude Code、Claude のアプリなど）
 ├─ クライアント 1 ── サーバー A（手元のファイル）
 ├─ クライアント 2 ── サーバー B（社内のデータベース）
 └─ クライアント 3 ── サーバー C（ネット上のサービス）
```

- **ホスト**：人が使う AI のアプリ
- **クライアント**：ホストの中で、サーバー1つにつき1つ作られる接続の係
- **サーバー**：データや道具を差し出すプログラム

## サーバーが渡せる3種類のもの

| 種類       | 中身                      | 例                                                   |
| ---------- | ------------------------- | ---------------------------------------------------- |
| ツール     | AI が呼び出して動かす機能 | 検索する、ファイルを書く、データベースに問い合わせる |
| リソース   | AI に読ませるデータ       | ファイルの中身、表の定義                             |
| プロンプト | よく使う頼み方のひな形    | 決まった形式で要約させる指示                         |

AI はまずサーバーに「何ができるか」の一覧を尋ねます。そのうえで、必要なときにツールを呼び出します。

## 手元とネット越しの2つのつなぎ方

|            | 手元のサーバー      | ネット越しのサーバー     |
| ---------- | ------------------- | ------------------------ |
| 通信の方式 | 標準入出力（stdio） | Streamable HTTP          |
| 動く場所   | 自分の PC の中      | サービスの会社のサーバー |
| 使う人     | ふつうは1人         | 多くの人が同時に使う     |
| 認証       | 不要なことが多い    | OAuth などでログインする |

<Callout type="warning">
  MCP サーバーは、AI
  にファイルの読み書きや外部サービスの操作を許します。入れる前に、作った人と、許す範囲を確かめてください。
</Callout>
