## 3行でいうと

1. CLAUDE.md は、Claude Code が作業の初めに毎回読む指示のファイル
2. 置き場所で効く範囲が変わる（自分の全プロジェクト・このプロジェクト・自分だけ）
3. `/init` で下書きを作り、200行より短く整える

## たとえば

```text
書く前：作業のたびに「テストは npm test で動かして」と伝える
書いた後：CLAUDE.md に「テスト：npm test」と1行あれば、毎回それを読んでから作業する
```

- 所要時間：10分
- 前に読む記事：[Claude Code を入れて、最初の作業を頼む](/claude-code/install-and-first-task/)

## 1. 置き場所を決める

| 置き場所              | 効く範囲             | 共有                              |
| --------------------- | -------------------- | --------------------------------- |
| `~/.claude/CLAUDE.md` | 自分の全プロジェクト | 自分だけ                          |
| `./CLAUDE.md`         | このプロジェクト     | Git でチームと共有                |
| `./CLAUDE.local.md`   | このプロジェクト     | 自分だけ（`.gitignore` に入れる） |

- 見つかったファイルは全部読まれ、上書きではなく足し合わされる
- 起動したフォルダーに近いものほど後に読まれる

## 2. ひな形を作る

```text
> /init
```

- Claude Code がプロジェクトを調べ、CLAUDE.md の下書きを作る
- すでにあるときは、上書きせずに直し方を提案する

## 3. 短く整える

```markdown
# このプロジェクトの決まり

## コマンド

- テスト：npm test
- 書式の確認：npm run lint

## 書き方

- TypeScript は strict。any を使わない
- 色はトークンから使い、直接書かない
```

- 1つのファイルは200行より短く保つ
- 長い説明は別のファイルに分け、`@docs/style.md` のように読み込ませる
- Claude が自分で見つけられることは書かない

<Callout type="warning">
  CLAUDE.md は守らせる仕組みではなく、読ませる指示です。必ず止めたい操作は、Hooks で止めます。
</Callout>

次は、保存のたびに整形を走らせる [Hooks の使い方](/claude-code/hooks-format/)です。
