CC 07　Claude Code のハウツー

Hooks で保存のたびに整形する

Claude Code がファイルを書き換えた直後に、Prettier を自動で走らせる設定です。うまく動かないときの見分け方まで扱います。

公式の変更の確認

次の見直し
2026-12-01 まで（30 日ごと）

整形を手で走らせ忘れると、差分に関係のない字下げの変更が混ざります。Hooks を使えば、書き換えの直後に決まったコマンドを自動で実行できます。

用意するもの

  • Prettier が入ったプロジェクト
  • .claude/settings.json を書き換えられること

設定を書く

書き換えのあとに動かしたいので、PostToolUse に登録します。対象は書き込みと編集の2つに絞ります。

注意

Hooks のコマンドは、あなたの権限でそのまま実行されます。共有のリポジトリに置くときは、中身を読んでから取り込みます。

動かして確かめる

  1. わざと字下げを崩したファイルを用意する。
  2. Claude Code に、そのファイルへ1行足すよう頼む。
  3. 保存のあと、字下げが直っていれば成功。

うまく動かないとき

症状見るところ
何も起きない/hooks で登録が読まれているか
整形されないファイルがあるPrettier の対象外の拡張子でないか
