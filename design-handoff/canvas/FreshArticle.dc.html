02

設定を書く

.claude/settings.json に次の設定を追加します。
既存の設定があれば、hooks の項目を統合してください。

.claude/settings.json
{
  "hooks": {
    "PostToolUse": [
      {
        "matcher": "Write|Edit",
        "hooks": [
          {
            "type": "command",
            "command": "npx prettier --write \"$(jq -r '.tool_input.file_path')\""
          }
        ]
      }
    ]
  }
}

イベントは標準入力に JSON で届きます。
jq で対象ファイルのパスを取り出します。

整形が走るタイミング
Write / Edit
書き換え完了
→
PostToolUse
JSON → jq
→
Prettier
自動で整形

エディターの保存操作ではなく、Claude Code の書き換えが起点です。

実行するコマンドを、必ず確認してください。

Hooks のコマンドは、あなたの権限で実行されます。
内容が分からないコマンドを、そのまま登録しないでください。

03

確かめる

ファイルの字下げを崩し、Claude Code に1行の追加を依頼します。
書き換えのあと、字下げも整えば成功です。

hello.js{{demoStatus}}
{{demoCode}}

整形の流れを、この場で試せます。

動かないとき

/hooks を開き、PostToolUse に登録されているか確認します。

拡張子が Prettier の対象か確認します。
.prettierignore で除外されていないかも確かめてください。
