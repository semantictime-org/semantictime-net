はじめての方へ

このサイトは、AI の使い方を「手元で動かして確かめた手順」としてまとめています。読み方を3つだけ覚えれば、どの記事も同じように読めます。

読み方は3つ

  1. 2026-11-01
    Claude Code 2.1.325

    記事の上に、確かめた日と版がある

    その日に、その版で、手順どおりに動いたという記録です。版が新しくなると動きが変わることがあります。

  2. CC 07

    記事には番号がある

    CC は Claude Code のように、記号は製品を表します。番号は記事ごとに決まっていて、変わりません。人に伝えるときは「CC07」で通じます。

  3. 見直し中

    公式が変わると「見直し中」になる

    公式の変更が記事に影響しそうなときに付けます。確かめ直すまでは、手順の一部が古いかもしれません。

やりたいことから選ぶ

  • 文章や資料をまとめたいClaude アプリ・ChatGPT・Gemini
  • コードを書かせたいClaude Code・Codex・Gemini CLI
  • 決まった作業を自動にしたいClaude Code・Agent SDK・MCP
  • 画像を作りたいMidjourney・FLUX ほか
  • 動画を作りたいSora・Veo ほか
  • 音声を作る・文字に起こしたいElevenLabs ほか

どの AI を使えばいいか迷ったら
